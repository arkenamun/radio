# Radio User Guide (Denmark Bushfire Brigades, WAERN)

A three-sheet A4 guide to WAERN radio use, prepared for the Training Working Group:

1. **WAERN Radios**: the Tait vehicle radio and the Vertex VX-829 handheld, and Denmark channels
2. **Talking on the Radio**: making a call, call signs, changing channel, prowords, the phonetic alphabet and the emergency message
3. **Common Radio Issues**: hum, two stations at once, and Talk-Around in a radio shadow

## Rebuilding the PDFs

You need Python 3, then:

```sh
cd src
python3 -m pip install -r requirements.txt
python3 -m playwright install chromium
sh build.sh
```

The PDFs and PNG previews land in `src/out/`. Each sheet's fit check is printed; `main_overflow` must be 0.

- Sheets 1 and 2 are generated by `build1.py` and `build2.py`: edit the text and drawings there, not in `sheets/`.
- Sheet 3 (`sheets/Main.dc.html`) is edited directly.
- `build.sh` adds the faint DRAFT watermark; remove that line for a final issue.
- The version and date are in each sheet's footer ("v1.3 · November 2026").
- The v2.0 draft is a separate build: `src/radio-user-guide.html` with `src/training.css`, rendered by `python3 src/render.py radio-user-guide.html out.pdf` (run from `src/`). `src/check.py` checks its fit.
- The v1.3 sheets are also kept as a design canvas on claude.ai, where they were drafted; this folder is the shareable copy.
